# Car Service & Repair Workshop Software

A comprehensive estimate and invoicing software system for car service and repair workshops.

## Features

- **Customer Management** - Manage customer details and vehicle information
- **Estimate Management** - Create and manage service estimates
- **Invoice Generation** - Generate invoices from estimates
- **Payment Tracking** - Track payments and outstanding balances
- **Reports & Analytics** - Revenue reports, outstanding invoices, and more

## Technology Stack

- Python with Flask
- SQLite Database
- Bootstrap UI
- Flask-SQLAlchemy ORM

## Installation

1. Clone the repository
2. Create a virtual environment
3. Install requirements
4. Run the application
